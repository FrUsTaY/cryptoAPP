# 🔐 Надёжный шифровальщик AES-256-GCM (Encryptor App)

![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)
![License](https://img.shields.io/badge/license-MIT-green)

Простое, но мощное графическое приложение для шифрования и расшифровки текста с использованием надежного алгоритма **AES-256-GCM**. Приложение написано на Python с использованием библиотеки `tkinter` для графического интерфейса и `cryptography` для обеспечения криптографической защиты.

## 🌟 Возможности

*   **Надежное шифрование**: Используется алгоритм AES в режиме GCM (Galois/Counter Mode) с длиной ключа 256 бит, обеспечивающий как конфиденциальность, так и аутентификацию данных.
*   **Безопасная генерация ключей**: Ключ шифрования генерируется из вашего пароля с использованием функции формирования ключа PBKDF2HMAC (SHA256) и уникальной соли.
*   **Графический интерфейс**: Интуитивно понятный и простой UI (построен на `tkinter`).
*   **Работа с буфером обмена**: Удобные кнопки для копирования результата и вставки текста.
*   **Работа с файлами**: Возможность сохранять зашифрованный (или расшифрованный) текст в текстовые файлы и загружать из них.
*   **Портативность**: Возможность сборки в один исполняемый файл `.exe` для работы без установки Python.

## 🛠️ Требования

Для запуска из исходного кода потребуется:
*   [Python 3.8+](https://www.python.org/downloads/)
*   Библиотека `cryptography`.

## 🚀 Инструкция по запуску (из исходников)

1. Склонируйте или скачайте репозиторий.
2. Установите необходимые зависимости. Рекомендуется использовать виртуальное окружение:
   ```bash
   pip install cryptography
   ```
3. Запустите приложение:
   ```bash
   python encryptor_app.py
   ```

## 📦 Инструкция по сборке (создание .exe)

Если вы хотите создать самостоятельный исполняемый файл для Windows, вы можете воспользоваться скриптом сборки:

1. Убедитесь, что у вас установлен `pyinstaller` и `cryptography`:
   ```bash
   pip install pyinstaller cryptography
   ```
2. Запустите скрипт сборки:
   ```cmd
   build.bat
   ```
3. После успешного завершения сборки готовый `.exe` файл можно найти в папке `dist\`.

*Примечание: для сборки используется иконка `icon.ico`.*

## 📖 Как использовать

1. **Пароль**: Введите надежный пароль в поле "Пароль (ключ)". *Запомните его, без него расшифровать данные будет невозможно!*
2. **Текст**: Вставьте или введите текст, который вы хотите зашифровать/расшифровать, в основное текстовое поле.
3. **Действие**:
   *   Нажмите **"🔒 Зашифровать"**, чтобы получить зашифрованный текст в формате Base64.
   *   Нажмите **"🔓 Расшифровать"**, чтобы преобразовать ранее зашифрованный текст обратно в читаемый вид (потребуется правильный пароль).
4. **Сохранение**: Вы можете скопировать результат в буфер обмена или использовать кнопку **"💾 Сохранить в файл"**.

---
*Внимание: Если пароль введен неверно или зашифрованные данные были изменены, процесс расшифровки завершится с ошибкой в целях безопасности.*
